หน้านี้เป็นตัวอย่างหน้าจอ หากปุ่มเล่นเกมไม่ปรากฏ แสดงว่าตัวดูไฟล์ไม่อนุญาตให้ JavaScript ทำงาน (พบบ่อยเมื่อเปิดไฟล์ HTML จากแอปบนมือถือ)

วิธีเปิดเกมให้เล่นได้จริง
🌐 เผยแพร่ผ่าน GitHub Pages

1. ดาวน์โหลดไฟล์นี้และตั้งชื่อเป็น index.html

2. อัปโหลดลง GitHub Repository (Public)

3. ไปที่ Settings → Pages → Deploy from a branch → main / (root) → Save

4. เปิดลิงก์เว็บไซต์ที่ GitHub Pages สร้างให้ จะสามารถกดเล่นและเซฟความคืบหน้าได้

หากต้องการลองบนคอมพิวเตอร์ สามารถเปิดไฟล์ HTML ใน Chrome หรือ Edge ได้โดยตรง
